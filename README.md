# Täglich Deutsch

Первый рабочий прототип Telegram-бота для ежедневной практики немецкого языка уровня A2.

## Что уже работает

- команда `/start` и тестовый мини-урок;
- приём голосового сообщения Telegram в формате OGG Opus;
- распознавание немецкой речи через Yandex SpeechKit;
- проверка ответа моделью GPT OSS 120B в Yandex AI Studio;
- короткая обратная связь по одному правилу урока;
- текстовый ответ вместо голосового для быстрой проверки.

## Ограничения прототипа

- голосовое сообщение — не более 30 секунд (ограничение синхронного SpeechKit API);
- доступен один тестовый урок про порядок слов;
- SpeechKit может самостоятельно восстанавливать некоторые грамматические окончания, поэтому прототип проверяет хорошо слышимый порядок слов;
- расписание, прогресс, оплата и остальные дни добавляются следующими модулями.

## Переменные окружения

Создайте на хостинге четыре переменные. Секретные значения нельзя добавлять в GitHub:

| Ключ | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | новый токен бота от BotFather |
| `YANDEX_API_KEY` | API-ключ Yandex AI Studio |
| `YANDEX_FOLDER_ID` | идентификатор каталога `taeglich-deutsch` |
| `YANDEX_MODEL` | `gpt-oss-120b/latest` |

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="..."
export YANDEX_API_KEY="..."
export YANDEX_FOLDER_ID="..."
python main.py
```

## Развёртывание на Bothost

1. Создайте отдельный GitHub-репозиторий и загрузите в него файлы из архива.
2. В Bothost выберите Telegram, Python 3.11 и регион Нидерланды.
3. Добавьте переменные окружения из таблицы выше.
4. Вставьте HTTPS-адрес репозитория и ветку `main`.
5. В качестве главного файла укажите `main.py`, если автодетект его не выберет.
6. Создайте и запустите бота, затем проверьте логи.

## Безопасность

- Не публикуйте `.env` и секретные ключи.
- Не вставляйте токены прямо в `main.py`.
- При утечке сразу отзовите старый ключ и создайте новый.
- Публичный репозиторий безопасен, если секреты находятся только в переменных окружения хостинга.
